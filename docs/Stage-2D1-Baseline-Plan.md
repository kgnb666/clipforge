## C. 技术方案

1. **架构影响**：2D 主体为验收，不新增架构组件；唯一新组件为 ARCH-011 要求的**日志模块**（`src-tauri/src/logging.rs`，std-only：应用路径 API 构造 `%LOCALAPPDATA%\com.clipforge.app\logs\`、单文件 5 MiB 轮转、保留 3 份、stderr 尾 8 KiB 截断复用 probe.rs 既有常量语义）。零新依赖、零 UI 变化。
2. **数据流变化**：无。日志为旁路写入（探测/退出摘要落到文件），不改变 IPC 数据、ProbeStateStore、ImportState 的任何语义。
3. **IPC 影响**：无新增命令、无参数变化（前端零改动）。
4. **生命周期影响**：无。D-0025/D-0026 的状态机、`shutdown_all`、取消不覆盖语义**原样冻结**；日志模块仅在既有事件点（探测失败、退出清理）追加旁路记录。
5. **对 2A/2B/2C 的影响**：均无行为影响（哈希级可验证，除新增 logging.rs 与 lib.rs 的挂载行外源码零改动）；2A 导入核心、2B 元数据语义、2C 生命周期管理逻辑不动。
