# ClipForge v0.1.0（首个交付版本）

**本地视频导入 · 元数据 · 格式转换** —— Windows 桌面客户端（Tauri 2 + React 19 + TypeScript）

## 下载安装

- **安装包**：`ClipForge_0.1.0_x64-setup.exe`（1.57 MiB，NSIS）
- 安装包未代码签名：首次运行若出现 SmartScreen"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**
- **前置依赖**：本机需有 FFmpeg / FFprobe（应用调用系统 FFmpeg 转码）：

  ```powershell
  winget install Gyan.FFmpeg
  ```

## 本版本能力

| 能力 | 说明 |
|---|---|
| 导入 | 系统文件对话框；路径校验（不存在/不可读分别报错）；同路径判重 |
| 元数据 | FFprobe：大小/时长/分辨率/视频编码/音频编码；无音轨如实显示；失败可重试 |
| 缩略图 | 真实首帧提取；缓存命中不重复；损坏媒体明确失败、不冒充 |
| 转换 | MP4（libx264 CRF23 + AAC + faststart）/ WebM（libvpx + libvorbis）；输出不覆盖、同名自动递增；失败清理半成品 |
| 可靠性 | 六类错误码 + 原始工具原因；超时/取消；关闭应用终止在途进程、无孤儿；日志轮转 5 MiB × 3 |

**已实测**：MP4 / MKV / MOV / AVI / WebM(VP9/Opus) / H.265 / AV1 输入（含无音轨）；中文+空格+`&`+`#`+`'`+括号 特殊路径全链路；损坏视频两条失败路径错误处理正确；安装/卸载干净。

## 质量与过程

- 真实 UI（Windows UI Automation）驱动验收：导入 → 元数据 → 缩略图 → 转换 → 卸载，逐项通过
- 工程文档：需求与验收规格、**决策日志 D-0001~D-0029**、**人机协作会话总结（含 AI 失误与纠正）**、各阶段报告与全部原始证据，均在仓库 `docs/` 下可逐项复核

## 已知限制

- 需要本机 FFmpeg；转 WebM（VP8）约为 MP4 的 5 倍耗时（默认超时 300s 内）
- 转换完成后提供"重新转换"（同格式）；切换格式需重新导入
- 未实现（按题目范围主动裁剪）：批量转换、播放器、字幕、AI 功能
