# ClipForge v0.1.1（功能优化版）

在 v0.1.0 基础上做了一轮**功能可见**的优化（不做批量转换/播放器/字幕/AI，保持题目范围）：

| 优化 | 说明 |
|---|---|
| **可切换输出格式** | 转换完成后除"重新转换"外，可直接 **[转 WebM] / [转 MP4]** 切换到另一种格式，无需重新导入（失败态亦可 [改用另一格式]） |
| **元数据扩展** | 新增 **帧率 / 比特率 / 容器格式** 三项（与前几项一样，缺失显示 `N/A`，数值可与 FFprobe 原始输出逐项核对） |
| **打开输出所在文件夹** | 转换完成后一键在资源管理器中定位输出文件（`/select` 选中） |
| **转换进度条** | 长视频转换显示实时百分比（183 秒素材实测可见）；总时长缺失的素材不显示进度、不造假 |

## 下载安装

- **安装包**：`ClipForge_0.1.1_x64-setup.exe`（未代码签名：首次运行若出现 SmartScreen"未知发布者"，点 **更多信息 → 仍要运行**）
- **前置依赖**：本机需有 FFmpeg / FFprobe：

  ```powershell
  winget install Gyan.FFmpeg
  ```

## 质量

- `cargo test`：**75 passed / 0 failed / 7 ignored**（较 0.1.0 新增 10 项单测，其中 converter 模块首次补齐单测）
- 真实 UI（Windows UI Automation）驱动验收：格式切换 / 新元数据字段（与 FFprobe JSON 对照一致）/ 打开文件夹（窗口与日志证据）/ 进度条（DOM 实测）+ **转换中关闭应用**（`CONV_CANCELLED`，无半成品、零残留进程）
- 全部工程过程文档与证据见仓库 `docs/`（决策日志 D-0001~D-0030、会话总结、各阶段报告）

## 提示

- 转 WebM（VP8）速度约为 MP4 的 5 倍；长视频请耐心等待（默认超时 300 秒）
- 详细功能与已知限制见 [README](../README.md)
